# 企业绿色评级系统 · 回归测试要点列表

> 目的：**任何一次修改后**（改菜单/样式/域名/接口/配置/组件），运行回归测试，确保"非修改部分功能不变"。
> 工具：`python3 tests/regression_test.py`（静态黄金基线，秒级，无需浏览器）+ `bash run_tests.sh`（全量：语法 + 基线 + 路由 + E2E）

---

## 一、一键运行方式

```bash
# 1) 静态回归（黄金基线，推荐每次改完必跑）
python3 tests/regression_test.py

# 2) 全量回归（基线 + 线上路由 + Playwright E2E TC01~TC07）
bash run_tests.sh

# 3) 指定线上地址跑全量
BASE_URL=https://uat.carbon-grading.com bash run_tests.sh
```

## 三、级别说明

| 级别 | 含义 | 失败处理 |
|------|------|---------|
| 🔒 黄金 | 基线固化，改动不应触碰；出现即失败 | 立即修复，不允许上线 |
| 👁 人工 | 需人眼核对（视觉/交互） | 对照截图确认后再上线 |

## 四、变更流程建议（每次修改的标准动作）

```
1. 修改代码
2. python3 tests/regression_test.py      ← 秒级基线，防"改A坏B"
3. node --check 产物（如改了 index.js）  ← 防白屏
4. bash run_tests.sh                      ← 全量回归（含 E2E）
5. 全绿 → 打包部署 → 上线后人工抽查视觉
```
